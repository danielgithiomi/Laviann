# Importing the Laviann design concepts into Figma Starter (Free)

You **do not need Figma Premium** for this handoff. Figma supports SVG import into
an editable design canvas. Its Starter plan includes unlimited personal drafts,
subject to the current Figma plan terms.

## Steps

1. Extract the **Laviann UX update** into your Laviann repository (or browse the
   provided design ZIP directly).
2. Open Figma, create a new **Design** file in your personal **Drafts**.
3. Drag any `.svg` from `docs/design/figma-import/` onto the Figma canvas.
4. Repeat for mobile screens and desktop screens. Space them by flow: Customer
   Home > Product > Checkout > Quotation; Vendor Dashboard > Inventory/Orders.
5. Open the Layers panel. Figma generally converts imported SVGs to **editable
   vector objects**. You can recolor/rearrange vectors and adjust paths.
6. For ongoing production edits, recreate key text, layout containers, components,
   grids, constraints and Auto Layout using Figma-native tools. Imported SVG text
   is **not guaranteed** to remain a native editable Figma text layer.
7. Use `tokens.json` and `brand-concept.md` as the source for your color styles.

## What you receive

- Nine self-contained SVGs (8 UI screens + palette board).
- Preview PNGs and a contact sheet to browse quickly.
- Editable written UX plan and token files to guide revisions.

## What these SVGs are NOT

- They are **not** native `.fig` source documents or fully interactive prototypes.
- They do **not** come with Auto Layout, component properties, or instance overrides.
- They are conceptual design references, **not** implemented Next.js screens.
- The illustrations are placeholders; replace them with actual product photography.
- There is no connected Figma account or automatic cloud publishing from ChatGPT.

## Suggested Figma draft naming

**Laviann - UX Concepts v0.1**

Group artboards by Customer Mobile, Customer Desktop, Vendor Desktop, Vendor
Mobile, and Branding. Keep the original SVGs as references while iterating.
